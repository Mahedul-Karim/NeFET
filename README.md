NeFT is a NFT selling and buying application where users can bid for a certain NFT or mint their own


## 💡 Key Features

- User login and registration
- NFT bidding and minting.

## Getting Started

First, run the development server:

npm run dev

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Route summary
- /items route for viewing all NFT
- /about route for learning more about NeFT
- /add-product is to add NFT
- /items/manage for managing added NFT
- /login for signing in the user
- /register for registraion
